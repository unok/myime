# ユーザー辞書は Mozc 形式を正本とし AzooKey へ一方向反映する

単語登録の保存先は Mozc ユーザー辞書（user_dictionary.db）を唯一の正本とする。AzooKey 変換への反映は、エンジン起動時と辞書更新時に全エントリを動的ユーザー辞書（メモリ上・非永続）としてプッシュする一方向同期で行う。Mozc 付属の単語登録ダイアログ・辞書ツール・インポート機能をそのまま編集 UI として使え、辞書データの置き場所が1つに保たれるため。

## Considered Options

- **AzooKey 側に独自のユーザー辞書永続化を持たせる**: 一覧編集・インポートの UI を自作する必要があり、正本が2つに割れる。却下。
- **双方向同期**: AzooKey 側から書き戻す動機がなく、複雑さだけが増える。却下。

## Consequences

- 品詞は JSON の `pos` に IPADIC left-id 定義の1〜6列目を結合した素性文字列を渡して AzooKey の CID へマッピングし、旧カテゴリ文字列も互換のため受け付ける。未知の素性文字列は普通名詞として扱う。
- 動詞・形容詞は活用形ごとに6〜14エントリへ展開されるため、動詞中心の辞書ではエントリ数が語数の数倍になる。
- 動的ユーザー辞書は非永続なので、エンジン初期化のたびにユーザー辞書全体を読み直してプッシュする必要がある。
